A modern, responsive personal portfolio website showcasing my projects, technical skills, experience, and journey in Software Engineering and Cybersecurity.

### ✨ Features
- Responsive and modern UI
- Dark / Light theme toggle
- Animated typing effect
- Interactive project filtering
- Animated statistics
- Mobile-friendly navigation
- Contact form with frontend validation

### 🛠️ Technologies Used
- **Languages:** HTML5, CSS3, JavaScript
- **CSS Framework:** Tailwind CSS
- **Icons:** Font Awesome
- **Fonts:** Google Fonts (Inter)
- **Browser APIs:** DOM, LocalStorage, Intersection Observer
- **Tools:** VS Code, Git, GitHub
